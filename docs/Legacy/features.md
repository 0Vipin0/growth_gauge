 **Current Features** :-

*   **Organized Counter Lists:**  Effortlessly manage and track all your ongoing tasks and timers within a clear and intuitive list.
*   **Detailed Counter Insights:** Dive deep into each counter with comprehensive detail views, including:
    *   **Heatmaps:**  Visually identify trends and peak activity periods over extended durations.
    *   **7-Day Charts:**  Quickly review your performance and counts for the past week at a glance.
*   **JSON and CSV Data Export:**  Securely export your valuable counter and timer data as JSON files for backup, sharing, or in CSV file for in-depth analysis with other tools.
*   **Persistent Data Storage:**  Enjoy peace of mind knowing your data is persistently stored using Shared Preferences, ensuring your progress is saved across all application sessions.
*   **Personalized App Experience:** Customize the look and feel of Growth Gauge to match your style by adjusting application themes and fonts directly within the settings.
*   **Local Authentication:** To protect your own private data from prying eyes of the other, local authentincation using Biometric with Pin Authentication as fallback ensure that the data is always yours to see.
*   **Scheduled Local Notification:** To keep you motivated to conitnuing the growth, scheduled local notifications are included allowing you to remember the idea of growth everyday.
*   **Automatic Build Release:** New version release files are generated with Github Action and available under releases.


**Realigned Features** :-

1.  **Personalized Fitness Profile (User Matrix):** Define specific, measurable goals, Baseline Biometrics (Height, Weight, Resting HR, etc.) and Constraints (injuries, equipment limitations).
2.  **Fitness Assessment:** Calculate a composite Fitness Score (e.g., Vitals, Stamina, Strength) based on user data and activity history.
3.  **Goal-Centric Activity Dashboard:** Effortlessly track and manage all ongoing activities (Count-Based/Time-Based). Group/Sort them by the goal they support and display a Progress Bar.
4.  **Comprehensive Activity Deep Dive:** Enhanced detail views including:
    * **Streak Heatmaps:** Visually plot consecutive activity days.
    * **Performance Charts (X-Day):** Review key metrics over flexible periods (7, 14, 30, 90 days).
    * **Daily Log:** Allow users to add mood, notes, and perceived effort (RPE) to daily entries.
5.  **Preset/Custom Workout Builder:** Create and save routines, utilizing templates (e.g., HIIT, Strength). Integrates core **Interval Timer functionality** with defined Work, Rest, and Cooldown periods.
6.  **Local Database:** Persistent data storage using an ORM database (e.g., Drift/SQLite) with mandatory support for **seamless DDL/Schema Migration**.
7.  **Biometric Data Protection (Local Lock):** Secure private data using native **Biometric Authentication** (Fingerprint/Face ID), with **PIN/Passcode** as a reliable fallback.
8.  **Voice-Guided Workout Coach:** Utilize **Text-to-Speech (TTS)** to provide audio cues and guidance tailored to the interval training templates, enabling hands-free follow-along.
9. **Growth Reminders:** Implement customizable **scheduled local notifications** that are personalized and reference the user's current goals or progress for motivation.
10. **Flexible UI Customization:** Offer users the capability to select **Light and Dark Modes (Themes)** and choose from a pre-configured set of **Accessible Fonts and Text Sizes**.
11. **Data Export & Import Utility:** Securely **Export** activity data as **JSON** (for backup/migration) and **CSV** (for analysis), and provide a robust **Import** function to restore data.
12. **Local Network Data Sync (LAN/Wi-Fi) (If Possible):** Synchronize the database across different OS devices (Android, Windows, Linux) connected over the **same local network**.
