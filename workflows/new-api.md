# Workflow: New API

## Skills

Apply:

- Repository Discovery
- Architecture Discovery
- Data Layer
- Networking
- Dependency Injection
- Testing
- Architecture Review
- Change Review

## Process

1. Identify the existing networking architecture.
2. Find a similar API integration.
3. Follow the existing client/data-source pattern.
4. Implement models according to project conventions.
5. Implement repository/data access if required.
6. Integrate dependencies.
7. Handle errors consistently.
8. Add tests.
9. Review architecture.
10. Validate.
