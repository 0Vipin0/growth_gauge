# Workflow: Project Onboarding

## Objective

Build a reliable understanding of an unfamiliar Flutter project.

## Skills

Apply:

- Repository Discovery
- Architecture Discovery
- Convention Discovery

## Process

1. Discover project structure.
2. Discover architecture.
3. Discover conventions.
4. Inspect representative features.
5. Inspect tests.
6. Inspect infrastructure.
7. Document project architecture if requested.

## Output

Create an architecture map containing:

- Project structure
- Feature structure
- State management
- Data flow
- Networking
- Dependency injection
- Navigation
- UI architecture
- Testing
- Code generation
- Important conventions
- Known inconsistencies
