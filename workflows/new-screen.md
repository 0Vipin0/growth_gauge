# Workflow: New Screen

## Skills

Apply:

- Repository Discovery
- Convention Discovery
- UI Development
- Navigation
- State Management
- Testing
- Change Review

## Process

1. Find a similar screen.
2. Inspect its structure.
3. Inspect navigation.
4. Inspect state ownership.
5. Inspect reusable UI components.
6. Implement the screen.
7. Add required state.
8. Add navigation.
9. Test important behavior.
10. Review consistency.
