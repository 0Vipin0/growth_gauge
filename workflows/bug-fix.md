# Workflow: Bug Fix

## Skills

Apply:

- Repository Discovery
- Architecture Discovery
- Testing
- Change Review

## Process

1. Understand the reported behavior.
2. Reproduce the issue when possible.
3. Identify the root cause.
4. Inspect surrounding architecture.
5. Find similar implementations.
6. Implement the smallest correct fix.
7. Add a regression test.
8. Validate.
9. Review for unintended changes.

## Rules

Prefer root-cause fixes.

Avoid unrelated refactoring.

Do not introduce architectural changes unless necessary.
