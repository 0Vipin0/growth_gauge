# Workflow: New Feature

## Objective

Implement a new feature while preserving project architecture.

## Skills

Apply:

- Repository Discovery
- Architecture Discovery
- Convention Discovery
- Feature Design
- State Management
- Data Layer
- UI Development
- Testing
- Architecture Review
- Change Review

## Process

### 1. Discover

Understand the project.

### 2. Find Reference

Find the closest existing feature.

### 3. Design

Define:

- Feature boundary
- State
- Data flow
- UI
- Navigation
- Tests

### 4. Implement

Reuse existing infrastructure.

### 5. Test

Add appropriate regression protection.

### 6. Review

Apply architecture review.

### 7. Validate

Apply final change review.

## Completion Criteria

The feature:

- Follows existing architecture.
- Uses existing infrastructure.
- Matches existing conventions.
- Does not introduce unnecessary dependencies.
- Has appropriate tests.
- Does not introduce architectural drift.
