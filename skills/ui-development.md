# Skill: UI Development

## Purpose

Create UI consistent with the existing application.

## Procedure

Inspect:

- Theme
- Colors
- Typography
- Spacing
- Components
- Icons
- Forms
- Loading states
- Empty states
- Error states
- Responsive behavior

Find existing components before creating new ones.

## Rules

Reuse existing design-system components.

Avoid hardcoded design values when project tokens exist.

Avoid duplicate components.

Keep widgets focused.

Keep business logic outside presentation when appropriate.

Consider accessibility and lifecycle safety.

## Expected Outcome

The new UI should visually, structurally, and behaviorally belong
to the existing application.
