# Skill: Convention Discovery

## Purpose

Identify the coding and structural conventions used by the repository.

## Inspect

- File naming
- Folder naming
- Class naming
- Method naming
- State naming
- Model naming
- Import organization
- Documentation style
- Widget organization
- Test naming
- Error naming
- Route naming
- Dependency registration
- Generated-file conventions

## Procedure

Find several representative examples.

Identify the dominant convention.

If conventions conflict:

1. Prefer current code.
2. Prefer actively maintained code.
3. Prefer the dominant pattern.
4. Avoid introducing another pattern.

## Expected Outcome

New code should use the same vocabulary, naming, organization,
and style as surrounding code.
