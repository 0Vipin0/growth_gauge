# Skill: Change Review

## Purpose

Perform a final quality review before considering work complete.

## Review

Check:

- Requirements
- Architecture
- Feature structure
- Naming
- State
- Data
- UI
- Navigation
- Error handling
- Accessibility
- Lifecycle safety
- Tests
- Dependencies
- Generated code
- Formatting
- Static analysis
- Scope

## Rules

Identify unrelated changes.

Identify accidental behavior changes.

Identify duplicated functionality.

Identify unnecessary complexity.

## Expected Outcome

The final implementation should be:

- Correct
- Consistent
- Testable
- Maintainable
- Focused
- Architecturally coherent
