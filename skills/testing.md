# Skill: Testing

## Purpose

Provide meaningful regression protection using the project's
existing testing strategy.

## Procedure

Discover:

- Test types
- Test organization
- Mocking
- Fixtures
- Naming
- Existing test utilities

Then test the behavior affected by the change.

Consider:

- Happy path
- Failure path
- Edge cases
- Loading
- Empty state
- Business rules
- User interaction

## Rules

Follow existing testing conventions.

Do not introduce another testing framework unnecessarily.

Prefer deterministic tests.

Test behavior rather than implementation details when practical.

## Expected Outcome

The change has appropriate regression protection.
